# FreshRoute Customer Flutter Mobile Application

Cross-platform iOS and Android customer laundry ordering application built with Flutter 3.

## Features
- **City & PIN Serviceability Discovery:** Bhilwara (311001), Kishangarh (305801), Jaipur (302017).
- **Service Catalog & Cart:** Wash & Fold (₹49/kg), Wash & Iron (₹89/kg), Steam Ironing (₹25/pc), Dry Clean (₹99/pc), Shoe Care (₹149/pair).
- **Slot Reservation:** 7:00 PM – 10:00 PM evening prime window.
- **Razorpay Payment Integration:** Seamless UPI, Cards, NetBanking.
- **Live Order Tracking:** Real-time tamper-proof QR bag identifier (`FRDYO9I8`) and status progression updates.

## How to Run
```bash
# Prerequisites: Flutter SDK >= 3.0.0
flutter pub get
flutter run
```
