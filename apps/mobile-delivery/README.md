# FreshRoute Valet & Delivery Partner Flutter Application

Cross-platform iOS and Android valet delivery partner application built with Flutter 3.

## Features
- **Valet Shift Management:** Active delivery tasks assigned for 7 PM – 10 PM windows.
- **Route Navigation:** Embedded Google Maps navigation to customer pickup and delivery locations.
- **QR Bag Scanner:** Verification of tamper-proof laundry bag codes during pickup, dark hub handover, and final delivery.
- **Proof of Delivery:** Customer signature capture and handover confirmation.

## How to Run
```bash
# Prerequisites: Flutter SDK >= 3.0.0
flutter pub get
flutter run
```
